02 / Things I’ve built

From work. For fun.

01Master Control TerminalPersonal project · FastAPI / React / TypeScript / PostgreSQL↗

I built a personal finance console to bring account activity, contribution room, holdings, and portfolio performance into one place.

Under the hood

Holdings and profit/loss are derived from transactions. The app handles contributions, trades, dividends, transfers, and currency exchanges, with funding checks and protection against selling more units than are held.

It also tracks RRSP, TFSA, and FHSA contribution room, combines market prices with manual valuations, and includes portfolio history, allocation views, and JSON backup/restore.

Explore the project on GitHub ↗

02Operations platformAt Brickeye · FastAPI / React / PostgreSQL↗

I led the architecture and development of a multi-tenant operations platform, working with the operations team to replace Airtable-based tracking.

The interesting part

Keeping device assignments and settings in sync with ThingsBoard, while supporting 3,200+ managed entities across 500+ organizations. FastAPI, React/TypeScript, PostgreSQL, and Redis connected the pieces.

Professional work · source code is private.

03Talk-to-My-CSVPersonal project · Streamlit / LangChain / Ollama↗

A natural-language interface for asking questions about CSV datasets, without writing SQL or code.

The experiment

Bringing Streamlit, LangChain, Ollama, and Chroma together to explore a more conversational way to work with data.

04When telemetry needs to become actionAt Brickeye · Python / PostgreSQL / Event-driven systems↗

I built and deployed a custom rules engine to evaluate device telemetry, generate alarms, and trigger notifications.

What kept me thinking

Reliable execution when things go wrong: transactional outbox patterns, idempotency, retries, dead-letter queues, and advisory locks.
